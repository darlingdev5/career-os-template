# Metrics — the only numbers allowed

Read this before writing ANY bullet. This file exists because inflated metrics get caught
in interviews, and under-claimed ones lose offers. Both are accuracy failures.

When in doubt: flag it, name the defensible version, let the owner decide.

## Scale-axis rule
When the target company operates at far larger scale than you have, leading with your user
count anchors you to the axis where you're outgunned. State scale once as context. Compete
on judgment and building.

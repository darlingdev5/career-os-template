# Applications

One folder per application: `YYYY-MM_company_role/`

What goes in it:
- `resume_<company>_<role>.docx` — the tailored resume
- `freetext_<role>.md` — application questions and your answers
- `outreach.md` — DMs, emails, who you contacted and when
- `call-notes.md` — written the same day, while you still remember the specifics
- any artifact you built (microsite, prototype, deck)

Keep the drafts you didn't send. The rejected version of a line is often the clue to what
the right one is.
